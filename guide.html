SkillBridge User Guide

This guide explains how to use the classroom prototype.

System Requirements

  • Desktop or laptop with Windows, macOS, or Linux.
  • A current web browser with JavaScript enabled.
  • 4 GB RAM as a basic target; 8 GB recommended for multitasking.
  • Internet connection when accessing the hosted website.

How to Use the Application

  1. Open the Application Prototype page.
  2. Use the sample employees or add fictional employees.
  3. Create responsibilities and select qualified employees for each task.
  4. Check the box next to an employee to mark them unavailable.
  5. Review the coverage results and cross-training recommendations.
  6. Select Reset Absences to return to normal coverage or Restore Sample Data to start over.

Coverage Status

StatusMeaning
CoveredTwo or more qualified employees available.
At RiskOne qualified employee available.
No CoverageNo qualified employees available.

Safety and Troubleshooting

Only use fictional data. Recommendations do not certify employee qualifications. If results do not change, check the task assignments and ensure JavaScript is enabled. Changes are saved in the current browser if storage is available; absence selections are temporary. No information is shared between users.
